# VibeBrace Studio — Guion de demostración

**Duración aproximada:** 5 minutos

## Objetivo

Demostrar el funcionamiento completo de VibeBrace Studio: crear una secuencia de vibración, enviarla al dispositivo, comprobar su funcionamiento, guardar y cargar un patrón, y exportar el código Arduino.

## 1. Presentación (30 segundos)

Presentar VibeBrace Studio como una aplicación que permite diseñar secuencias de vibración desde una interfaz web y comunicarlas con un Arduino mediante conexión USB.

## 2. Crear una secuencia (1 minuto)

- Abrir VibeBrace Studio en el navegador.
- Mostrar el formulario para agregar pasos.
- Crear una secuencia utilizando distintos tipos de pasos.
- Mostrar cómo los pasos aparecen en la lista y en el canvas.
- Explicar brevemente que cada paso tiene parámetros de intensidad y duración.

## 3. Enviar y probar el dispositivo (1 minuto)

- Conectar el Arduino por USB.
- Seleccionar el puerto correspondiente y conectar.
- Enviar la secuencia con el botón de ejecución.
- Comprobar que el dispositivo responda a la secuencia.
- Mostrar los mensajes de actividad en el registro de la aplicación.

**Precaución:** comenzar con intensidades bajas, comprobar que los motores estén correctamente instalados y detener la ejecución si se produce alguna molestia.

## 4. Guardar y cargar un patrón (1 minuto)

- Guardar la secuencia creada en un archivo JSON.
- Mostrar dónde se guarda el archivo.
- Cargar nuevamente el patrón.
- Comprobar que los pasos y sus parámetros se recuperan correctamente.

## 5. Exportar código Arduino (1 minuto)

- Utilizar la opción de exportación Arduino.
- Mostrar el código generado.
- Descargar o guardar el archivo `.ino`.
- Explicar que la exportación permite obtener una representación de la secuencia en código Arduino.

## 6. Cierre (30 segundos)

Resumir las funcionalidades demostradas:

- Diseño visual de secuencias.
- Comunicación con Arduino.
- Ejecución y detención de patrones.
- Guardado y carga mediante JSON.
- Exportación de código Arduino.
- Validación de patrones y manejo de errores.

**Resultado esperado:** demostrar el recorrido completo desde el diseño de un patrón hasta su ejecución, almacenamiento y exportación.
